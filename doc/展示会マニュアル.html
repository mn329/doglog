GO2 AIR ・ お手・おすわりデモ ・ スタッフ用

Go2 展示会マニュアル

プログラムを知らなくても、この順に進めれば動かせます。Go2 はその場から歩かず、手の形を見て お手・おすわり・立つ・首かしげ をします。

止めたいときは
スペース

すぐ止めて一時停止します。画面に PAUSED と出て、手には反応しなくなります。もう一度押すと再開します。

押す前に、映像のウィンドウを一度クリックしておく。
それでも止まらない・倒れそうなら、スマホのアプリかリモコンで止める。

お客さんの手の形

右手で 1.5 秒そのまま
✋
パー → お手右前足を上げる。座っていれば先に立つ h
☝️
人差し指 → おすわり中指は軽く曲げればよい s
✊
グー → 立つ座っているときだけ u
✌️
チョキ → 首かしげ座っているときは何もしない v
  • Go2 から約 1m、手のひらを Go2 の顔に向けて、指を上に。
  • 左手・遠くの手・下を向いた手には反応しない。
  • 動いている約 4 秒（画面に赤い BUSY）は受け付けない。同じ形をもう一度させるには、一度手を下ろす。
  • キー（h s u v）はスタッフ用。一時停止中も効く。ESC で止めて終了。

安全のルール

最初に読む

  • Go2 のまわり 1m にロープやテープで線を引き、お客さんは線の外から手を見せる。
  • 小さな子どもが Go2 に近づいたら、スタッフが間に入る。
  • お手をするのは右前足。足が下りてくる場所に手を置かないよう「手は足の少し前に、ひらを見せて」と声をかける。
  • 迷ったらスペースキー。それでも止まらなければアプリかリモコン。
  • Go2 を持ち上げたり、動いているときに触ったりしない。
  • ハートは使わない。後ろ足で立ち上がる大きな動きで、倒れたり人に当たったりするおそれがある。チョキでは代わりに首かしげをする。

つなぎ方を選ぶ

Go2 と Mac のつなぎ方は 3 通り。事前に試して動いたものを当日使う。会場の Wi-Fi は使わない

いちばん簡単

Go2 直結（AP モード）

展示会スタート(Go2直結).command
  • ルーターもスマホも要らない
  • Go2 の IP は 192.168.12.1 に決まっていて、変わらない
  • Go2 を AP モードに切り替える必要がある
  • Mac はその間インターネットに出られない（デモには影響なし）
  • Air で使えるかは未確認

持ち運び用ルーター

展示会スタート.command
  • 安定している。Mac もインターネットを使える
  • ルーターによっては IP の自動検索が通らない

スマホのテザリング

展示会スタート.command
  • ルーターが要らない
  • iPhone は「互換性を優先」をオン（2.4GHz）
  • スマホは充電しながら専用に。電話や電池切れで切れる
  • IP の自動検索が通らないことがある

Go2 直結のつなぎ方

  1. アプリで Go2 の Wi-Fi の設定を AP モード（Go2 が自分で Wi-Fi を出す）にする。Wi-Fi の名前とパスワードを控える
  2. アプリを完全に終了する
  3. Mac の Wi-Fi を Go2 の Wi-Fi に切り替える
  4. 展示会スタート(Go2直結).command をダブルクリック

ルーターやテザリングに戻すときは、アプリで Go2 を STA モード（ほかの Wi-Fi につなぐ）に戻す。

テザリングのつなぎ方

  1. スマホのテザリングをオン（iPhone は「互換性を優先」も）
  2. アプリで Go2 の接続先 Wi-Fi をテザリングに変える
  3. Mac もテザリングにつなぐ
  4. 展示会スタート.command をダブルクリック

「見つかりませんでした」で接続できないときは、アプリで Go2 の IP（172.20.10.x のような番号）を調べ、.env の GO2_IP を書き換える。

人が多いとき

前を大勢が通っても誤作動しないよう、4 つのふるいを入れています

小さく映る手は無視

--min-size 0.12

後ろを通る人の手は小さく映る。画面の size の行に右手の大きさが出る。

下を向いた手は無視

DOWN

ぶら下げて歩く人の手は使わない。size の行で大きさの横に DOWN と出る。

いちばん近い手だけ

R

右手が何人分映っても、いちばん大きい手だけ使う。その手に R、ほかは灰色。

同じ手で 1.5 秒

--hold 1.5

手の位置が急に飛んだら別の人とみなして数え直す。通り過ぎる手では動かない。

値は起動ファイル（2 つとも）をテキストエディタで開き、--hold 1.5 --min-size 0.12 の数字を書き換えます。

困っていること変える値
遠くの人の手で動いてしまう--min-size を大きく（0.12 → 0.15）
近くで見せても反応しないsize が min より小さいなら --min-size を小さく（0.12 → 0.09）。または「もう少し近くで」と声をかける
写真のピースで勝手に動く--hold を長く（1.5 → 2.0）。チョキを止めるなら --victory none
反応が遅いと言われる--hold を短く（1.5 → 1.0）
それでも誤作動するスペース で一時停止にして、キーで動かす

--min-size の決め方: 会場で、お客さんに立ってほしい位置（約 1m）から右手を見せて size を読み、その 7 割くらいにする。0.12 は仮の値で、Go2 のカメラではまだ確かめていません。

チョキの動き（ハートの代わり）

どれもその場で、足を上げない動き

候補--victory動き向き
首かしげtilt 既定立ったまま体を約 14° 横に傾けて戻す。いちばん小さく、写真のピースで急に動いても危なくない◎
おしりふりwiggleおしりを左右にふる○
うれしいcontent体をゆらす○
伸びstretch前足を伸ばして伸びをする。前に人がいると近い△
なしnoneチョキに反応しない。人が多すぎるとき—

外したもの: ハート・ダンス・宙返り・ジャンプ・飛びかかり・逆立ち・寝転がり（大きい・倒れるおそれ）、脱力 Damp（その場で崩れ落ちる）。

どれも Go2 Air で動くかは未確認です（確認済みはお手・おすわり・立つだけ）。事前に 1 つずつ試します。

cd ~/Documents/doglog/go2-hand-follow
source .venv/bin/activate
python try_action.py tilt       # 首かしげ
python try_action.py wiggle     # おしりふり
python try_action.py content    # うれしい
python try_action.py stretch    # 伸び
# Go2 直結のときは最後に --ap を付ける（例: python try_action.py tilt --ap）

判断は Go2 を見て行います。使えない動きでも応答コード 0 のまま動かないことがあります。「応答コード」「応答なし」が出たら使えない可能性が高いです。同じ動きを 2 回続けて試し、元の姿勢にきれいに戻るかも見ます。

持ち物と事前準備

展示会の前日まで・開発担当

持ち物

  • Go2 Air 本体、充電済みバッテリー（予備があれば）、充電器
  • リモコン（あれば）と、Unitree Go アプリが入ったスマホ（非常停止・立たせる用）
  • Mac と充電器
  • 選んだつなぎ方に必要なもの（持ち運び用ルーター、またはテザリング用のスマホと充電ケーブル。Go2 直結なら不要）
  • ロープ・テープ（1m の線）、お客さん向けの手の形の案内

準備

  1. 3 通りのつなぎ方を試して、当日使うものを決める。Go2 直結が使えればいちばん簡単。
  2. .env に GO2_SN（シリアル番号）と GO2_AES_KEY を書く（doc/実機接続手順.md の 3・4）。IP は起動時に自動で探す（Go2 直結では探さないので GO2_AES_KEY だけでよい）。
  3. 本番のつなぎ方で「見つけました」と出ることを確かめる。ルーターやテザリングによっては自動検索が通らず、.env の古い GO2_IP を使ってしまう。
  4. 当日使う起動ファイルで、当日チェックを一通り行う。
  5. チョキの動きを try_action.py で試して決める。
  6. 会場と同じくらいの明るさ・距離で --min-size を決める。

実機でまだ確かめていないこと

  • Go2 直結（AP モード）とテザリングでつながるか
  • 首かしげなど、ハートの代わりの動きが Air で動くか
  • --min-size 0.12 が Go2 のカメラで約 1m に当たるか
  • 受け付けない時間 4 秒と、座った状態からお手をするときの待ち時間 2 秒が足りているか
  • 座った状態から立つときに前に出る原因
  • 手を 4 つまで検出しても fps が下がりすぎないか
