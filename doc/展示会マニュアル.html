Go2 展示会マニュアル

プログラムを知らなくても、この順に進めれば動かせます。Go2 はその場から歩かず、手の形を見て、お手・おすわり・立つ・首かしげをします。

スペース

すぐ止めて一時停止します。画面に PAUSED と出て、手に反応しなくなります。もう一度押すと再開します。

お客さんの手の形

右手で 1.5 秒そのまま
✋
パー → お手右前足を上げる。座っていれば先に立つ　h
☝️
人差し指 → おすわり中指は軽く曲げればよい　s
✊
グー → 立つ座っているときだけ　u
✌️
チョキ → 首かしげ約 30° 傾けて戻す。座っているときは何もしない　v
  • Go2 から約 1m で、手のひらを Go2 の顔に向け、指を上に。
  • 左手・遠くの手・下を向いた手には反応しません。
  • 動いている約 4 秒（画面に赤い BUSY）は受け付けません。同じ形をもう一度させるときは、一度手を下ろします。
  • キー h s u v はスタッフ用で、一時停止中も効きます。ESC で終了します。

安全のルール

最初に読む

  • Go2 のまわり 1m にロープやテープで線を引き、お客さんは線の外から手を見せる。
  • 小さな子どもが Go2 に近づいたら、スタッフが間に入る。
  • お手をするのは右前足。足が下りてくる場所に手を置かないよう、「手は足の少し前に、ひらを見せて」と声をかける。
  • 迷ったらスペースキー。それでも止まらなければアプリかリモコン。
  • 動いているときは Go2 に触らない。持ち上げるのは、下の「前に出てしまったとき」だけ。
  • 立つとき・お手のあとに少しずつ前に出るので、Go2 の前は空けておく。

前に出てしまったとき

  1. Go2 を持ち上げて、ゆっくり後ろ（元の位置）に下げて置く。
  2. 足が交差したら、持ち上げたまま電源を OFF にする。交差したまま床に置くと、倒れたり足を傷めたりするおそれがある。

持ち上げるときは胴を両手で持つ。約 15kg あるので、できれば 2 人で。脚の関節のすき間に指を入れない（脚が動くとはさまれる）。

事前準備

展示会の前日までに、当日使う Mac で一度だけ。Go2 は要らない。インターネットのある場所で、15 分ほど

VS Code も Python も、入れなくてよいです。プログラムは GitHub Desktop で取ってきて、あとは「セットアップ.command」が全部入れます。することは、クリックと、受け取った値の貼り付けだけです。

  1. 開発担当から 2 つ受け取る。
    • GitHub の招待：会社の GitHub（dotlog-inc）への招待メールが届いたら「Join」を押す。GitHub のアカウントがなければ、先に github.com で作り、ユーザー名を開発担当に伝える。
    • 接続情報：シリアル番号・Go2 の IP・AES キー（32 桁）。AES キーは Go2 を動かす鍵なので、人に見せない・メモやチャットに残さない。
    値どこでわかるか
    シリアル番号Unitree Go アプリの機体の情報、または本体のラベル。わからなければ空のまま Enter でよい（IP でつなぐ）
    Go2 の IPUnitree Go アプリのネットワークの情報。テザリングなら 172.20.10.x（10/23 は 172.20.10.4）。前日にわからなければ 172.20.10.4 を入れておき、当日違ったら IPを変える.command
    AES キー開発担当から受け取る（取り方は下の「配る側」）。機体ごとに 1 つで、毎回は変わらない
  2. GitHub Desktop を desktop.github.com からダウンロードして入れ、開いて自分の GitHub アカウントでサインインする。
  3. GitHub Desktop のメニュー File → Clone Repository… を開き、一覧から dotlog-inc/doglog を選んで Clone。
    • 一覧に出ないときは、招待の「Join」がまだ。メールを確かめる。
    • 保存先は最初に入っている場所（書類 → GitHub → doglog）のままでよい。
  4. GitHub Desktop のメニュー Repository → Show in Finder でフォルダを開き、セットアップ.command をダブルクリックする。
    • 「開けません」「開発元を確認できません」と出たら「完了」を押し、システム設定 → プライバシーとセキュリティ の下のほうにある「このまま開く」を押して、Mac のパスワードを入れる。ほかの .command でも、初めて開くときに出たら同じようにする。
  5. 黒い画面（ターミナル）が開き、[1/5] から [5/5] まで進む。途中でシリアル番号・IP・AES キーを聞かれたら、貼り付けて Enter。
    • AES キーは貼り付けても画面に出ないが、入っている。そのまま Enter。
  6. 「○ 準備OK」と出たら完了。Enter で閉じる。「×」が出たら、画面を写真に撮って開発担当に送る。
  7. カメラで試す.command をダブルクリックし、Mac のカメラで手の形を試す（Go2 にはつながない）。
    • 「"ターミナル" がカメラへのアクセスを求めています」と出たら「許可」。
    • 映像のウィンドウで右手を 1.5 秒見せる。パーで PAW、人差し指で SIT、そのあとグーで STAND、チョキで VICTORY と左上に出て done になれば、準備は全部できている。ESC で終わる。
    • 手の形の練習にもなる。当日お客さんに説明する人は、ここで慣れておく。

当日、初めて Go2 につないだとき

展示会スタート.command を開いて「"ターミナル" がローカルネットワーク上のデバイスを検索…」と出たら「許可」。「許可しない」を押してしまったら、システム設定 → プライバシーとセキュリティ → ローカルネットワーク で「ターミナル」をオンにする。オフのままだと Go2 につながらない。

Go2 の IP が前日に入れたものと違ったら、IPを変える.command で入れ直す。

新しい版にするとき

開発担当から「更新した」と言われたら、GitHub Desktop を開いて上の Fetch origin を押し、Pull origin に変わったらもう一度押す。そのあと セットアップ.command をもう一度ダブルクリックする（接続情報は聞かれない）。

起動ファイルの数字（--min-size など）を書き換えていると、GitHub Desktop の左に変更が出て Pull できないことがある。開発担当に相談する。

配る側（開発担当）

招待: GitHub の dotlog-inc → doglog → Settings → Collaborators（または組織の People）で、相手の GitHub ユーザー名を招待する。読むだけなら Read の権限でよい。

プログラムの更新: 開発用のリポジトリで直して実機で確かめたら、./sync_expo.sh で展示会用のフォルダ（~/Documents/doglog/doglog-expo）にコピーし、そこでコミットして push する。展示会用のリポジトリを直接直すと、次のコピーで消える。.env（AES キー）と models/ はリポジトリに入っていない。

接続情報: 3 つとも、自分の Mac の go2-hand-follow/.env に入っている（Finder で ⌘+Shift+. を押すと見える。テキストエディットで開く）。一から取るときは、AES キーを Unitree のアカウントで取り出す（パスワードを聞かれる。一覧の「AES-128 key」の列）。--device-type Go2 を付けないと「0 devices」になる。渡すときは、相手の Mac でセットアップするときに隣で貼り付けるのがいちばん安全。

cd ~/Documents/doglog/go2-hand-follow
.venv/bin/unitree-fetch-aes-key --email <アカウントのメールアドレス> --device-type Go2

GitHub のアカウントがない人には zip: 次のコマンドで「デスクトップ」に作る。受け取った人は zip をダブルクリックして開き、doglog フォルダを「書類」に移してから 4. へ（「このまま開く」が .command ごとに 1 回ずつ出る）。

git -C ~/Documents/doglog/doglog-expo archive --prefix=doglog/ -o ~/Desktop/doglog.zip main

つなぎ方

本番は iPhone のテザリング。会場の Wi-Fi は混んでいて切れやすいので使わない

本番 ・ 10/23 に実機で動いた

iPhone のテザリング

事前に一度だけ

  • iPhone の名前（設定 → 一般 → 情報 → 名前）を英数字だけにする（例: Mina）。テザリングの Wi-Fi はこの名前になる。日本語や ’ が入っていると Go2 がつなげない。
  • 設定 → インターネット共有 の「Wi-Fi のパスワード」を控える。

Go2 をテザリングにつなぐ

  1. iPhone のインターネット共有で「ほかの人の接続を許可」と「互換性を優先」をオン
  2. Unitree Go アプリで
    Device→Network→Connection mode→Wi-Fi Mode
  3. 名前に iPhone の名前、パスワードにテザリングのパスワードを入れて Next
    • 名前の欄にはスマホが今つながっている Wi-Fi が入っていることがあるので、必ず書き換える
    • Internet remote connection はオンにする（10/23 はオンでつながった）
    • 「not found」と出たら、iPhone のインターネット共有の画面を開いてからもう一度
  4. アプリを完全に終了し、Mac もテザリングにつなぐ
  5. 展示会スタート.command をダブルクリック

一度つないだ設定は Go2 が覚えているので、次からは同じ iPhone のテザリングをオンにすれば自動でつながる。通信の遅れは平均 26ms で、デモには十分。

人が多いとき

前を大勢が通っても誤作動しないよう、4 つのふるいを入れています

小さく映る手は無視

--min-size 0.12

後ろを通る人の手は小さく映る。画面の size の行に右手の大きさが出る。

下を向いた手は無視

DOWN

ぶら下げて歩く人の手は使わない。size の行で大きさの横に DOWN と出る。

いちばん近い手だけ

R

右手が何人分映っても、いちばん大きい手だけ使う。その手に R、ほかは灰色。

同じ手で 1.5 秒

--hold 1.5

手の位置が急に飛んだら別の人とみなして数え直す。通り過ぎる手では動かない。

値は起動ファイルを右クリック →「このアプリケーションで開く」→「テキストエディット」で開き、--hold 1.5 --min-size 0.12 の数字だけを書き換えて保存します。

困っていること変える値
遠くの人の手で動いてしまう--min-size を大きく（0.12 → 0.15）
近くで見せても反応しないsize が min より小さいなら --min-size を小さく（0.12 → 0.09）。または「もう少し近くで」と声をかける
写真のピースで勝手に動く--hold を長く（1.5 → 2.0）。チョキを止めるなら --victory none
反応が遅いと言われる--hold を短く（1.5 → 1.0）
それでも誤作動するスペース で一時停止にして、キーで動かす

--min-size の決め方: 会場で、お客さんに立ってほしい位置（約 1m）から右手を見せて size を読み、その 7 割くらいにします。0.12 は仮の値で、Go2 のカメラではまだ確かめていません。

持ち物と開場前の準備

前日まで（Go2 なし）と、当日の開場前（Go2 あり）

持ち物

  • Go2 Air 本体、充電済みバッテリー（予備があれば）、充電器
  • リモコン（あれば）と、Unitree Go アプリが入ったスマホ（非常停止・立たせる用）
  • Mac と充電器
  • テザリング用の iPhone と充電ケーブル（テザリング専用にする）
  • ロープ・テープ（1m の線）、お客さん向けの手の形の案内

前日まで（Go2 なしでできる）

  1. 当日使う Mac で「事前準備」を済ませ、カメラで試す.command で手の形が判定されることまで確かめる。
  2. テザリング用の iPhone の名前を英数字だけにし、「互換性を優先」をオンにしておく（つなぎ方）。
  3. Go2 のバッテリー・リモコン・iPhone を充電しておく。

当日、開場前（Go2 が要る）

  1. Go2 をテザリングにつなぐ（つなぎ方）。前にテザリングにつないだ Go2 なら、電源を入れれば自動でつながる。
  2. 展示会スタート.command で「見つけました」「接続OK」と出ることを確かめる。ローカルネットワークの「許可」もこのとき。
  3. 当日の起動チェックを一通り行い、首かしげ（約 30°）がきれいに動くことを見る。
  4. 会場の明るさ・距離で --min-size を決める（人が多いとき）。

わかっている問題点（10/26 時点）

  • 立つとき・お手のあとに少しずつ前に出る。立ち方を変えて減らした（座った状態から立つと約 15cm → 約 5cm）が、なくなっていない。当日は人の手で戻す（安全のルール）。
  • 接続の予備が弱い。テザリング用の iPhone の電池切れ・着信で止まる。AP モードは Air で使えず、予備はルーターだけ。
  • Go2 の IP の自動検索が不安定で、古い GO2_IP を使ってしまうことがある。IP が変わったら IPを変える.command で入れ直す。
  • 黒い画面に「応答なし」「InvalidStateError」が出る。返事が遅れて届くだけで、実害はない。

実機でまだ確かめていないこと

  • 首かしげ以外のチョキの動き（おしりふり・うれしい・伸び）が Air で動くか
  • --min-size 0.12 が Go2 のカメラで約 1m に当たるか
  • 前に出るのを止める方法（立ち方を変えても、展示会デモでは前に出てしまう）
  • 受け付けない時間 4 秒が足りているか
  • 手を 4 つまで検出しても fps が下がりすぎないか

10/23 に確認済み: テザリングでの接続、首かしげ、お手・おすわり・立つ、ESC で立ってから終わること。
