Go2 展示会マニュアル

プログラムを知らなくても、この順に進めれば動かせます。Go2 はその場から歩かず、手の形を見て、お手・おすわり・立つ・首かしげをします。

すぐ止めて一時停止します。画面に PAUSED と出て、手に反応しなくなります。もう一度押すと再開します。

お客さんの手の形

右手で 1.5 秒そのまま
✋
パー → お手右前足を上げる。座っていれば先に立つ　h
☝️
人差し指 → おすわり中指は軽く曲げればよい　s
✊
グー → 立つ座っているときだけ　u
✌️
チョキ → 首かしげ約 30° 傾けて戻す。座っているときは何もしない　v
  • Go2 から約 1m で、手のひらを Go2 の顔に向け、指を上に。
  • 左手・遠くの手・下を向いた手には反応しません。
  • 動いている約 4 秒（画面に赤い BUSY）は受け付けません。同じ形をもう一度させるときは、一度手を下ろします。
  • キー h s u v はスタッフ用で、一時停止中も効きます。ESC で終了します。

安全のルール

最初に読む

  • Go2 のまわり 1m にロープやテープで線を引き、お客さんは線の外から手を見せる。
  • 小さな子どもが Go2 に近づいたら、スタッフが間に入る。
  • お手をするのは右前足。足が下りてくる場所に手を置かないよう、「手は足の少し前に、ひらを見せて」と声をかける。
  • 迷ったらスペースキー。それでも止まらなければアプリかリモコン。
  • 動いているときは Go2 に触らない。持ち上げるのは、下の「前に出てしまったとき」だけ。
  • 立つとき・お手のあとに少しずつ前に出るので、Go2 の前は空けておく。

前に出てしまったとき

  1. Go2 を持ち上げて、ゆっくり後ろ（元の位置）に下げて置く。
  2. 足が交差したら、持ち上げたまま電源を OFF にする。交差したまま床に置くと、倒れたり足を傷めたりするおそれがある。

持ち上げるときは胴を両手で持つ。約 15kg あるので、できれば 2 人で。脚の関節のすき間に指を入れない（脚が動くとはさまれる）。

初めての Mac の準備

その Mac で一度だけ。インターネットのある場所で、10 分ほど

VS Code も Python も、入れなくてよいです。必要なものは「セットアップ.command」が全部入れます。することは、ダブルクリックと、受け取った値の貼り付けだけです。

  1. 開発担当から 2 つ受け取る。
    • go2-hand-follow.zip（プログラムのフォルダ）
    • 接続情報：シリアル番号・Go2 の IP・AES キー（32 桁）。AES キーは Go2 を動かす鍵なので、人に見せない・メモやチャットに残さない。
  2. zip をダブルクリックして開き、出てきた go2-hand-follow フォルダを「書類」に移す。
  3. フォルダの中の セットアップ.command をダブルクリックする。
    • 「開けません」「開発元を確認できません」と出たら「完了」を押し、システム設定 → プライバシーとセキュリティ を開く。下のほうの「"セットアップ.command" はブロックされました」の横の「このまま開く」を押し、Mac のパスワードを入れる。
    • ほかの .command も、初めて開くときに 1 回ずつ同じことが出る。同じように開く。
  4. 黒い画面（ターミナル）が開き、[1/5] から [5/5] まで進む。途中でシリアル番号・IP・AES キーを聞かれたら、貼り付けて Enter。
    • AES キーは貼り付けても画面に出ないが、入っている。そのまま Enter。
  5. 「○ 準備OK」と出たら完了。Enter で閉じる。「×」が出たら、画面を写真に撮って開発担当に送る。
  6. 初めて 展示会スタート.command を開いたとき、「"ターミナル" がローカルネットワーク上のデバイスを検索…」と出たら「許可」。
    • 「許可しない」を押してしまったら、システム設定 → プライバシーとセキュリティ → ローカルネットワーク で「ターミナル」をオンにする。オフのままだと Go2 につながらない。

配る側（開発担当）

zip は次のコマンドで作る。.venv（Mac ごとに作り直す）、.env（AES キー）、models/（顔のデータ）は入れない。接続情報は zip とは別に、直接渡す。

cd ~/Documents/doglog && zip -r go2-hand-follow.zip go2-hand-follow \
  -x 'go2-hand-follow/.*' 'go2-hand-follow/.*/*' 'go2-hand-follow/models/*' \

     'go2-hand-follow/experiments/*' '*/__pycache__/*'

つなぎ方

本番は iPhone のテザリング。会場の Wi-Fi は混んでいて切れやすいので使わない

本番 ・ 10/23 に実機で動いた

iPhone のテザリング

事前に一度だけ

  • iPhone の名前（設定 → 一般 → 情報 → 名前）を英数字だけにする（例: Mina）。テザリングの Wi-Fi はこの名前になる。日本語や ’ が入っていると Go2 がつなげない。
  • 設定 → インターネット共有 の「Wi-Fi のパスワード」を控える。

Go2 をテザリングにつなぐ

  1. iPhone のインターネット共有で「ほかの人の接続を許可」と「互換性を優先」をオン
  2. Unitree Go アプリで
    Device→Network→Connection mode→Wi-Fi Mode
  3. 名前に iPhone の名前、パスワードにテザリングのパスワードを入れて Next
    • 名前の欄にはスマホが今つながっている Wi-Fi が入っていることがあるので、必ず書き換える
    • Internet remote connection はオンにする（10/23 はオンでつながった）
    • 「not found」と出たら、iPhone のインターネット共有の画面を開いてからもう一度
  4. アプリを完全に終了し、Mac もテザリングにつなぐ
  5. 展示会スタート.command をダブルクリック

一度つないだ設定は Go2 が覚えているので、次からは同じ iPhone のテザリングをオンにすれば自動でつながる。通信の遅れは平均 26ms で、デモには十分。

人が多いとき

前を大勢が通っても誤作動しないよう、4 つのふるいを入れています

小さく映る手は無視

--min-size 0.12

後ろを通る人の手は小さく映る。画面の size の行に右手の大きさが出る。

下を向いた手は無視

DOWN

ぶら下げて歩く人の手は使わない。size の行で大きさの横に DOWN と出る。

いちばん近い手だけ

R

右手が何人分映っても、いちばん大きい手だけ使う。その手に R、ほかは灰色。

同じ手で 1.5 秒

--hold 1.5

手の位置が急に飛んだら別の人とみなして数え直す。通り過ぎる手では動かない。

値は起動ファイルを右クリック →「このアプリケーションで開く」→「テキストエディット」で開き、--hold 1.5 --min-size 0.12 の数字だけを書き換えて保存します。

困っていること変える値
遠くの人の手で動いてしまう--min-size を大きく（0.12 → 0.15）
近くで見せても反応しないsize が min より小さいなら --min-size を小さく（0.12 → 0.09）。または「もう少し近くで」と声をかける
写真のピースで勝手に動く--hold を長く（1.5 → 2.0）。チョキを止めるなら --victory none
反応が遅いと言われる--hold を短く（1.5 → 1.0）
それでも誤作動するスペース で一時停止にして、キーで動かす

--min-size の決め方: 会場で、お客さんに立ってほしい位置（約 1m）から右手を見せて size を読み、その 7 割くらいにします。0.12 は仮の値で、Go2 のカメラではまだ確かめていません。

持ち物と事前準備

展示会の前日まで

持ち物

  • Go2 Air 本体、充電済みバッテリー（予備があれば）、充電器
  • リモコン（あれば）と、Unitree Go アプリが入ったスマホ（非常停止・立たせる用）
  • Mac と充電器
  • テザリング用の iPhone と充電ケーブル（テザリング専用にする）
  • ロープ・テープ（1m の線）、お客さん向けの手の形の案内

準備

  1. テザリングでつながることを確かめる（予備にルーターも）。
  2. 当日使う Mac で セットアップ.command を済ませておく（初めての Mac の準備）。AES キーの取り方は doc/実機接続手順.md の 3（開発担当だけ）。
  3. テザリングで「見つけました」と出ることを確かめる。見つからないと .env の古い GO2_IP を使ってしまう。
  4. 起動ファイルで、当日チェックを一通り行う。
  5. 会場と同じくらいの明るさ・距離で --min-size を決める。

わかっている問題点（10/26 時点）

  • 立つとき・お手のあとに少しずつ前に出る。立ち方を変えて減らした（座った状態から立つと約 15cm → 約 5cm）が、なくなっていない。当日は人の手で戻す（安全のルール）。
  • 接続の予備が弱い。テザリング用の iPhone の電池切れ・着信で止まる。AP モードは Air で使えず、予備はルーターだけ。
  • Go2 の IP の自動検索が不安定で、古い GO2_IP を使ってしまうことがある。IP が変わったら IPを変える.command で入れ直す。
  • 黒い画面に「応答なし」「InvalidStateError」が出る。返事が遅れて届くだけで、実害はない。

実機でまだ確かめていないこと

  • 首かしげ以外のチョキの動き（おしりふり・うれしい・伸び）が Air で動くか
  • --min-size 0.12 が Go2 のカメラで約 1m に当たるか
  • 前に出るのを止める方法（立ち方を変えても、展示会デモでは前に出てしまう）
  • 受け付けない時間 4 秒が足りているか
  • 手を 4 つまで検出しても fps が下がりすぎないか

10/23 に確認済み: テザリングでの接続、首かしげ、お手・おすわり・立つ、ESC で立ってから終わること。
