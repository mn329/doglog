# 展示会マニュアル（Go2 お手・おすわりデモ）

展示会で Go2 Air を動かす人向けの手順。プログラムを知らなくても、この順に進めれば動かせる。

展示会で使うのは **お手・おすわりデモ（`go2_trick.py`）だけ**。Go2 はその場から歩かない。
手を追いかける追従デモ（`go2_follow.py`）は、人混みでは別の人の手を追って歩き出すおそれがあるので**使わない**。

## 事前準備（展示会の前日までに、当日使う Mac で。Go2 は要らない）

**何も入れる必要はない。** `セットアップ.command` を開くだけ。インターネットのある場所で、15 分ほどかかる。

1. 開発担当から 2 つ受け取る。
   - **GitHub の招待**：会社の GitHub（dotlog-inc）への招待メールが届いたら「Join」を押す。GitHub のアカウントがなければ、先に github.com で作り、ユーザー名を開発担当に伝える。
   - **接続情報**：シリアル番号・Go2 の IP・**AES キー**（32 桁）。AES キーは Go2 を動かす鍵なので、人に見せない・メモやチャットに残さない。

   | 値 | どこでわかるか |
   |---|---|
   | シリアル番号 | Unitree Go アプリの機体の情報、または本体のラベル。**わからなければ空のまま Enter でよい**（IP でつなぐ） |
   | Go2 の IP | Unitree Go アプリのネットワークの情報。テザリングなら `172.20.10.x`（10/23 は `172.20.10.4`）。前日にわからなければ `172.20.10.4` を入れておき、当日違ったら `IPを変える.command` |
   | AES キー | 開発担当から受け取る（取り方は下の「配る側」）。機体ごとに 1 つで、毎回は変わらない |

2. **GitHub Desktop** を desktop.github.com からダウンロードして入れ、開いて自分の GitHub アカウントでサインインする。
3. GitHub Desktop のメニュー **File → Clone Repository…** を開き、一覧から `dotlog-inc/doglog` を選んで **Clone**。
   - 一覧に出ないときは、招待の「Join」がまだ。メールを確かめる。
   - 保存先は最初に入っている場所（書類 → GitHub → doglog）のままでよい。
4. GitHub Desktop のメニュー **Repository → Show in Finder** でフォルダを開き、`セットアップ.command` を**ダブルクリック**する。
   - 「開けません」「開発元を確認できません」と出たら「完了」を押し、**システム設定 → プライバシーとセキュリティ** の下のほうにある**「このまま開く」**を押して、Mac のパスワードを入れる。ほかの `.command` でも、初めて開くときに出たら同じようにする。
5. 黒い画面（ターミナル）が開き、`[1/5]` から `[5/5]` まで進む。途中でシリアル番号・IP・AES キーを聞かれたら、**貼り付けて Enter**（AES キーは貼り付けても画面に出ないが、入っている）。
6. **「○ 準備OK」**と出たら完了。Enter で閉じる。**「×」**が出たら、画面を写真に撮って開発担当に送る。
7. `カメラで試す.command` をダブルクリックし、**Mac のカメラで**手の形を試す（Go2 にはつながない）。
   - 「"ターミナル" がカメラへのアクセスを求めています」と出たら「許可」。
   - 映像のウィンドウで右手を 1.5 秒見せる。パーで `PAW`、人差し指で `SIT`、そのあとグーで `STAND`、チョキで `VICTORY` と左上に出て `done` になれば、準備は全部できている。ESC で終わる。
   - 手の形の練習にもなる。当日お客さんに説明する人は、ここで慣れておく。

**当日、初めて Go2 につないだとき**: `展示会スタート.command` を開いて「"ターミナル" がローカルネットワーク上のデバイスを検索…」と出たら**「許可」**。「許可しない」を押してしまったら、システム設定 → プライバシーとセキュリティ → ローカルネットワーク で「ターミナル」をオンにする。オフのままだと Go2 につながらない。Go2 の IP が前日に入れたものと違ったら、`IPを変える.command` で入れ直す。

**新しい版にするとき**: 開発担当から「更新した」と言われたら、GitHub Desktop を開いて上の **Fetch origin** を押し、**Pull origin** に変わったらもう一度押す。そのあと `セットアップ.command` をもう一度ダブルクリックする（接続情報は聞かれない）。起動ファイルの数字（`--min-size` など）を書き換えていると、GitHub Desktop の左に変更が出て Pull できないことがある。開発担当に相談する。

| ダブルクリックするファイル | いつ |
|---|---|
| `セットアップ.command` | 事前準備で一度だけ。新しい版にしたときと、うまく動かなくなったときにも押してよい |
| `カメラで試す.command` | Go2 なしで、Mac のカメラで手の形を試すとき（前日の確認・練習） |
| `展示会スタート.command` | 当日、Go2 とつないでデモを始めるとき |
| `IPを変える.command` | 「見つかりませんでした」と出てつながらないとき。アプリで調べた Go2 の IP を入れる |

### 配る側（開発担当）

- **招待**: GitHub の dotlog-inc → doglog → Settings → Collaborators（または組織の People）で、相手の GitHub ユーザー名を招待する。読むだけなら Read の権限でよい。
- **プログラムの更新**: 開発用のリポジトリで直して実機で確かめたら、`./sync_expo.sh` で展示会用のフォルダ（`~/Documents/doglog/doglog-expo`）にコピーし、そこでコミットして push する。展示会用のリポジトリを直接直すと、次のコピーで消える。`.env`（AES キー）と `models/` はリポジトリに入っていない。
- **接続情報**: 3 つとも、自分の Mac の `go2-hand-follow/.env` に入っている（Finder で ⌘+Shift+. を押すと見える。テキストエディットで開く）。一から取るときは、AES キーを Unitree のアカウントで取り出す（パスワードを聞かれる。一覧の「AES-128 key」の列）。`--device-type Go2` を付けないと「0 devices」になる。渡すときは、相手の Mac でセットアップするときに隣で貼り付けるのがいちばん安全。

  ```bash
  cd ~/Documents/doglog/go2-hand-follow
  .venv/bin/unitree-fetch-aes-key --email <アカウントのメールアドレス> --device-type Go2
  ```

- **GitHub のアカウントがない人には zip**: 次のコマンドで「デスクトップ」に作る。受け取った人は zip をダブルクリックして開き、`doglog` フォルダを「書類」に移してから 4. へ（「このまま開く」が `.command` ごとに 1 回ずつ出る）。

  ```bash
  git -C ~/Documents/doglog/doglog-expo archive --prefix=doglog/ -o ~/Desktop/doglog.zip main
  ```

## 1. 安全のルール（最初に読む）

- **Go2 のまわり 1m にロープやテープで線を引き**、お客さんは線の外から手を見せる。
- 小さな子どもが Go2 に近づいたら、スタッフが間に入る。
- お手をするのは **右前足**。足が下りてくる場所に手を置かないよう、「手は足の少し前に、ひらを見せて」と声をかける。
- 止めたいときは、迷わず **スペースキー**（2. の表）。それでも止まらないときは、**Go2 の体を持ち上げて、電源ボタンを長押しする**（電源が切れる。7.）。
- 動いているときは Go2 に触らない。持ち上げるのは、下の「前に出てしまったとき」だけ。
- 立つとき・お手のあとに少しずつ前に出るので、Go2 の前は空けておく。
- **前に出てしまったとき**は、Go2 を持ち上げて、ゆっくり後ろ（元の位置）に下げて置く。**足が交差したら、持ち上げたまま電源を OFF にする**（交差したまま床に置くと、倒れたり足を傷めたりするおそれがある）。
- 持ち上げるときは**胴を両手で**持つ。約 15kg あるので、できれば 2 人で。**脚の関節のすき間に指を入れない**（脚が動くとはさまれる）。

## 2. 操作早見表

### お客さん（右手で、1.5秒そのまま）

| 手の形 | Go2 の動き |
|---|---|
| ✋ パー | お手（右前足を上げる）。座っていれば先に立つ |
| ☝️ 人差し指だけ | おすわり |
| ✊ グー | 立つ |
| ✌️ チョキ | 首かしげ（体を少し横に傾ける）。座っているときは何もしない |

- **右手**だけに反応する。左手は灰色で表示され、使われない。
- Go2 から **約 1m 以内**で、手のひらをカメラ（顔の正面）に向け、**指を上に向ける**。遠くの手と、指が下を向いた手（下げた手）は無視される。
- 1回動いたら、同じ形をもう一度させるには一度手を下ろす。
- 動いている間（約4秒、画面に赤い `BUSY`）は次の指示を受け付けない。
- チョキは写真のピースでも出るので、座っているときは反応しない（立ち上がらない）。

### スタッフ（Mac のキーボード）

画面のウィンドウを一度クリックしてから押す。

| キー | 動き |
|---|---|
| **スペース** | **すぐ止めて一時停止**（画面に `PAUSED`）。ジェスチャーに反応しなくなる。もう一度押すと再開 |
| `s` | おすわり |
| `u` | 立つ |
| `h` | お手 |
| `v` | 首かしげ |
| ESC | 止めて終了 |

一時停止中もキー（`s` `u` `h` `v`）は効く。人が多すぎて誤作動しそうなときは、一時停止にしてキーで動かす。

## 3. つなぎ方を選ぶ

Go2 と Mac のつなぎ方は 3 通り。**事前に試して動いたものを当日使う。** 起動するファイルが違う。

**2026-10-23 の実機テストでは、テザリングで動いた（本番はテザリングを使う）。** Go2 直結（AP モード）は、アプリで切り替えても Mac から Go2 の Wi-Fi が見つからず、使えなかった。

| つなぎ方 | 起動するファイル | 良いところ | 気をつけること |
|---|---|---|---|
| **スマホのテザリング（本番）** | `展示会スタート.command` | ルーターが要らない。Mac もインターネットを使える。**実機で動いた**（通信の遅れは平均 26ms で問題なし） | テザリング役のスマホは充電しながら専用にする（電話や電池切れで切れる）。Go2 につなぐ設定にコツがある（下の手順） |
| 持ち運び用ルーター（予備） | `展示会スタート.command` | 安定している。Mac もインターネットを使える | ルーターによっては IP の自動検索が通らない。途中で Go2 の IP が変わったことがある |
| Go2 直結（AP モード） | `展示会スタート(Go2直結).command` | ルーターもスマホも要らない | **Air では使えなかった**（10/23）。Wi-Fi の名前の最後は切り替えるたびに変わる |

会場の Wi-Fi は混んでいて切れやすいので使わない。

### Go2 直結（AP モード）のつなぎ方（Air では使えなかった。参考）

1. Unitree Go アプリで、Go2 の Wi-Fi の設定を **AP モード**（Go2 が自分で Wi-Fi を出す）に切り替える。Go2 の Wi-Fi の名前とパスワードを控える。
2. アプリを完全に終了する。
3. Mac の Wi-Fi を、Go2 の Wi-Fi に切り替える。
4. `展示会スタート(Go2直結).command` をダブルクリックする。IP は探さず、すぐ接続する。

元に戻すとき（ルーターやテザリングで使うとき）は、アプリで Go2 の Wi-Fi を STA モード（ほかの Wi-Fi につなぐ）に戻す。

### テザリングのつなぎ方（本番）

**事前に一度だけ（iPhone の準備）**

- iPhone の名前（「設定 → 一般 → 情報 → 名前」）を**英数字だけ**にする（例: `Mina`）。テザリングの Wi-Fi の名前はこの名前になる。日本語や `’` が入っていると Go2 がつなげない。
- 「設定 → インターネット共有」の「Wi-Fi のパスワード」を控える。

**Go2 をテザリングにつなぐ**

1. iPhone の「設定 → インターネット共有」で「ほかの人の接続を許可」をオン、「**互換性を優先**」もオン（2.4GHz になり、Go2 から見えるようになる）。
2. Unitree Go アプリで **Device → Network → Connection mode** の **Wi-Fi Mode** を選ぶ。
3. 名前の欄に**テザリングする iPhone の名前**（「情報」の名前）、パスワードの欄に**テザリングのパスワード**を入れて Next。**「Internet remote connection」はオン**にする（10/23 はオンでつながった）。
   - 名前の欄には、スマホが今つながっている Wi-Fi が自動で入っていることがあるので、必ず書き換える。
   - 「not found」と出たら、iPhone の「インターネット共有」の画面を開いてから、もう一度試す（この画面を開いている間はほかの機器から見つけやすい）。
4. つながったら、**アプリを完全に終了する**。
5. Mac もテザリングにつなぐ。
6. `展示会スタート.command` をダブルクリックする。「Go2 (...) を 172.20.10.x で見つけました」と出れば OK（10/23 は `172.20.10.4`）。
   - 「見つかりませんでした」と出て接続できないときは、アプリで Go2 の IP（`172.20.10.x`）を調べ、`IPを変える.command` をダブルクリックして入れる。

一度つないだ設定は Go2 が覚えているので、次からは iPhone のテザリングをオンにすれば、Go2 の電源を入れたときに自動でつながる（同じ iPhone・同じ名前・同じパスワードのとき）。

## 6. 当日の起動手順

1. Go2 の電源を入れ、立ち上がるまで約1分待つ。
2. スマホの Unitree Go アプリで、Go2 が**立っている**ことを確かめる。座っていたらアプリで立たせる。
3. **アプリを完全に終了する**（上にスワイプして閉じる）。アプリがつながったままだと Mac からつながらない。
4. Mac を、3. で選んだ Wi-Fi（ルーター／テザリング／Go2 の Wi-Fi）につなぐ。
5. Finder で `doglog` フォルダ（書類 → GitHub → doglog）を開き、**起動ファイルをダブルクリック**する（Go2 直結なら `展示会スタート(Go2直結).command`、それ以外は `展示会スタート.command`）。
   - 「開けません」と出たら、「事前準備」の 4。
6. 黒い画面に「接続OK」と出て（ルーター・テザリングではその前に「Go2 (...) を ... で見つけました」）、Go2 のカメラ映像のウィンドウが開けば準備完了。
7. 自分の右手でパー・人差し指・グー・チョキを試し、動くことを確かめてからお客さんを迎える。

**Go2 は立った状態で起動する。** 座っているか立っているかはプログラムが覚えているだけなので、起動後にアプリで姿勢を変えると、表示（画面左上の `STANDING` / `SITTING`）と実際がずれる。ずれたら一度 ESC で終了し、Go2 を立たせてから起動し直す。

## 7. 止める・終わる

| 場面 | すること |
|---|---|
| 少し様子がおかしい | **スペースキー**で一時停止。落ち着いたらもう一度スペース |
| プログラムが反応しない | 黒い画面（ターミナル）をクリックして Ctrl+C |
| それでも止まらない・倒れそう | **Go2 の体を持ち上げて、電源ボタンを長押しする**（電源が切れる）。持ち上げるときは胴を両手で、脚の関節に指を入れない |
| 休憩・終了 | ESC で終了（座っていれば、立ってから終わる。数秒待つ）→（必要なら）アプリで伏せさせて電源を切る |

休憩中にバッテリーを替えるときは、ESC で終了してから。再開は 6. の 1 から。

## 8. 人が多いときの調整

人がたくさん前を通っても誤作動しないように、次の 4 つを入れている。

- **小さく映る手は無視する（`--min-size`）**: 後ろを通る人の手は小さく映るので使わない。画面の `size 0.xx (min 0.12)` の行に、映っている右手の大きさが出る。
- **下を向いた手は無視する**: 指が真横より下を向いた手（下げた手、ぶら下げて歩く人の手）は使わない。`size` の行で、その手の大きさの横に `DOWN` と出る。
- **近い手を優先する**: 右手が何人分か映っても、いちばん大きく（近く）映った手だけを使う。使っている手には `R` の印が付き、ほかは灰色。
- **同じ手で 1.5 秒続けたときだけ動く（`--hold`）**: 手の位置が急に飛んだら（別の人の手に入れ替わったら）数え直す。通り過ぎる人の手では動かない。

値は起動ファイル（`展示会スタート.command` と `展示会スタート(Go2直結).command` の両方）の中の `--hold 1.5 --min-size 0.12` で変える。ファイルを右クリック →「このアプリケーションで開く」→「テキストエディット」で開き、**数字だけ**を書き換えて保存する。

| 困っていること | 変える値 |
|---|---|
| 遠くの人の手で動いてしまう | `--min-size` を大きく（0.12 → 0.15） |
| 近くで手を見せても反応しない（`size` が min より小さい） | `--min-size` を小さく（0.12 → 0.09）。または「もう少し近くで」と声をかける |
| 写真のピースなどで勝手に動く | `--hold` を長く（1.5 → 2.0）。チョキを止めるなら `--victory none` |
| 反応が遅いと言われる | `--hold` を短く（1.5 → 1.0） |

決め方: 会場で、お客さんに立ってほしい位置（約 1m）から右手を見せて `size` の値を読み、その **7 割くらい**を `--min-size` にする。`0.12` は仮の値で、Go2 のカメラではまだ確かめていない。

## 9. チョキの動き（ハートの代わり）

ハート（FingerHeart）は使わない。代わりの候補（どれもその場で、足を上げない動き）:

| 候補 | `--victory` | 動き | 展示会向きか |
|---|---|---|---|
| 首かしげ | `tilt`（既定） | 立ったまま体を約 30° 横に傾けて戻す（実機で確認済み） | ◎ その場で足を上げない動きなので、写真のピースで急に動いても危なくない |
| おしりふり | `wiggle` | おしりを左右にふる | ○ その場の動き。かわいい |
| うれしい | `content` | 体をゆらす | ○ |
| 伸び | `stretch` | 前足を伸ばして伸びをする | △ 前に体を伸ばすので、前に人がいると近い |
| なし | `none` | チョキに反応しない | 人が多すぎるとき |

外したもの: ハート・ダンス・宙返り・ジャンプ・飛びかかり・逆立ち・寝転がり（大きい／倒れるおそれ）、脱力（Damp。その場で崩れ落ちる）。

**首かしげ以外は、Go2 Air で動くかまだ確かめていない**（実機で確かめたのはお手・おすわり・立つ・首かしげ）。事前に 1 つずつ試す:

```bash
cd ~/Documents/GitHub/doglog
.venv/bin/python try_action.py wiggle     # おしりふり
.venv/bin/python try_action.py content    # うれしい
.venv/bin/python try_action.py stretch    # 伸び
# Go2 直結のときは最後に --ap を付ける（例: .venv/bin/python try_action.py wiggle --ap）
```

**判断は Go2 を見て行う。** 使えない動きでも応答コードが 0 のまま、何も動かないことがある。「応答コード ...（0以外は失敗の可能性）」や「応答なし」が出たら、使えない可能性が高い。
同じ動きを **2 回続けて** 試し、2 回目もきれいに動いて元の姿勢に戻るかも見る。動いたものの中から選び、起動ファイルの `--victory` を書き換える。

## 10. 困ったとき

| 症状 | 対処 |
|---|---|
| `RobotBusyError` | アプリが開いたまま。アプリを完全に終了し、10〜20 秒待ってからダブルクリックし直す |
| 「見つかりませんでした」のあと `LocalSignalingPortError` | Mac と Go2 が同じルーター（テザリング）につながっているか確かめる。Go2 を起動して 1 分たったか確かめる。IP を調べて `IPを変える.command` で入れる。ローカルネットワークの許可（「事前準備」の「当日、初めて Go2 につないだとき」）も確かめる |
| 「開けません」「開発元を確認できません」 | システム設定 → プライバシーとセキュリティ →「このまま開く」（「事前準備」の 4） |
| 「カメラ 0 を開けません」（カメラで試すとき） | システム設定 → プライバシーとセキュリティ → カメラ で「ターミナル」をオンにして、もう一度ダブルクリック |
| 「まだ準備ができていません」 | 先に `セットアップ.command` をダブルクリックする |
| セットアップで「×」が出る | インターネットにつながっているか確かめて、もう一度ダブルクリック。だめなら画面を写真に撮って開発担当へ |
| Go2 直結で `LocalSignalingPortError` | Mac の Wi-Fi が Go2 の Wi-Fi になっているか確かめる。Go2 が AP モードになっているか、アプリで確かめる |
| 映像のウィンドウが出ない | 数秒待つ。出なければ ESC（または Ctrl+C）で終了してやり直す |
| 手に反応しない | 右手か／手のひらを向けているか／指が上を向いているか（`DOWN` と出ていないか）／`size` が min より大きいか を見る。逆光（窓や照明を背にしている）なら Go2 の向きを変える |
| 画面が白っぽく、手が見えない | `white` の値が高い。照明の向きを変える。それでもだめなら `展示会スタート.command` の最後に `--gamma 2.0` を足す |
| 動きがカクカク・遅い | 画面の fps が 10 より低い。ほかのアプリを閉じる。ルーターと Go2 を近づける |
| `STANDING` / `SITTING` の表示が実際と逆 | ESC で終了し、Go2 を立たせてから起動し直す（6.） |
| 立つとき・お手のあとに前に出る | 持ち上げて、ゆっくり後ろに下げて置く。**足が交差したら、持ち上げたまま電源を OFF**（1. を参照）。立ち方を変えて減らしたが、なくなってはいない |
| 黒い画面に `応答なし` や `InvalidStateError` がたくさん出る | Go2 の返事が遅れて届いているだけ。動いていれば気にしなくてよい |

それ以外は [実機接続手順.md](実機接続手順.md) のトラブルシューティングを見る。

## わかっている問題点（2026-10-26 時点）

- **立つとき・お手のあとに少しずつ前に出る。** 立ち方を変えて減らした（座った状態から立つと約 15cm → 約 5cm）が、なくなっていない。当日は人の手で戻す（1.）。
- **接続の予備が弱い。** テザリング用の iPhone の電池切れ・着信で止まる。AP モードは Air で使えず、予備はルーターだけ。
- Go2 の IP の自動検索が不安定で、古い `GO2_IP` を使ってしまうことがある。IP が変わったら `IPを変える.command` で入れ直す。
- 黒い画面に「応答なし」「InvalidStateError」が出る。返事が遅れて届くだけで、実害はない。
